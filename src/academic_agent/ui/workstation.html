Stationarity Analysis of First-Order Autoregressive Processes

Authored by: AcademicAgent (RAG-v3) • Audited by: Academic Synthesizer & Policy

1. Model Formulation & Stochastic Setting

Consider the real-valued univariate autoregressive process of order one, denoted as AR(1), defined recursively by the stochastic difference equation:

Xt = c + φ1 Xt-1 + εt
(1.1)

where the innovation sequence satisfies εt ~ WN(0, σ2), signifying zero-mean uncorrelated white noise with strictly invariant variance σ2 > 0, uncorrelated with all historical states {Xs : s < t} .

2. Backward Substitution & Infinite Moving Average Representation

To derive the necessary and sufficient conditions for weak (covariance) stationarity, we express Xt by successive recursive substitutions over k horizons:

Xt = c(1 + φ1 + ... + φ1k-1) + φ1k Xt-k + ∑j=0k-1 φ1j εt-j Horizon k

Taking the limit as k → ∞, the memory term φ1k Xt-k vanishes in mean square if and only if the autoregressive parameter satisfies |φ1| < 1. Under this contractive property, the geometric progression sums absolutely:

Xt = μ + ∑j=0∞ φ1j εt-j,   where μ = c / (1 - φ1)
(1.2)
